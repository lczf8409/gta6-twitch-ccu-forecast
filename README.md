Forecasts Grand Theft Auto VI's launch-day Twitch viewers hour by hour: a log-ratio regression on hour-1 size across past launches, outputting five quantiles per hour for hours 2–24. Launch-day curves are strongly shaped by how big hour 1 is — a huge first hour peaks early and decays, a small one keeps building as regions unlock — so each hour's log ratio is regressed on log hour-1 viewers across comparable past launches, with a calibrated normal spread around it.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
